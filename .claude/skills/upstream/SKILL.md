# 원본 따라잡기

kit 은 원본 저장소의 한 커밋에서 갈라진 포크다. 원본은 계속 바뀌는데 kit 은 그것을 저절로 받지 못한다. 이 스킬은 기준 커밋 뒤의 원본 변경을 빠짐없이 훑고, 하나씩 반영하거나 버리고, 기준 커밋을 올린다.

기준 커밋은 `README.md` 맨 아래 원본 링크 옆 「(커밋 <sha>)」 한 곳에만 있다. 원본 이름과 kit 이름의 대응은 `docs/authoring.md` 의 「이름 대응」 표 한 곳에만 있다. 스크립트는 둘 다 거기서 읽는다.

## 1. 바뀐 것을 뽑는다

```bash
python3 -I .claude/skills/upstream/upstream.py
```

출력은 기준 커밋부터 원본 `main` 까지, 원본 폴더를 건드린 커밋마다 kit 쪽 대상으로 묶은 파일 목록이다. 머지 커밋은 뺀다. 머지 커밋의 차이는 다른 커밋이 이미 보여 준 변경을 되풀이한다.

- `[대응] <kit 경로>`: 대응표로 찾은 kit 의 스킬·파일. 원본 플레이북은 kit 의 같은 이름 플레이북으로 간다.
- `[옮기지 않기로 함]`: 대응표에 `(옮기지 않음)` 으로 적은 원본 스킬.
- `[대응표에 없음]`: 원본에 새로 생긴 스킬. 3단계에서 대응표에 줄을 더한다.
- `[기타]`: 원본의 매니페스트, 가이드, 다른 하네스 문서. kit 에 같은 파일이 없다.
- 끝 줄 「대응표에 없는 원본 스킬」은 원본 스킬 목록 전체를 대응표와 견준 결과다.

## 2. 커밋마다 원본 차이를 읽고 정한다

```bash
gh api repos/<원본 저장소>/commits/<sha> --jq '.files[] | select(.filename|startswith("<원본 폴더>/")) | "### \(.filename)\n\(.patch)"'
```

`[대응]` 대상마다 원본 차이와 지금 kit 파일을 나란히 읽고 셋 중 하나로 정한다.

- **반영.** 원본의 바뀐 규칙이나 시험을 kit 파일에 한국어로 다시 쓴다. 원본 글을 옮겨 붙이지 않는다. `/dev:write` 기준으로 쓰고, 원본 이름(라우터 이름, 원칙 스킬 이름)은 본문에 남기지 않는다(`docs/authoring.md`).
- **이미 있음.** kit 이 같은 것을 먼저 바꿨거나 다른 장치로 이미 막는다. 어디서 막는지 파일 경로를 댄다.
- **버림.** kit 의 방향과 맞지 않는다. kit 이 그 규칙을 훅이나 시험으로 옮겨 산문을 일부러 지운 경우, 원본이 쓰는 도구가 Claude Code 에 없는 경우가 그렇다. 이유를 한 줄로 쓴다.

원본이 글을 줄인 변경은 kit 에서도 줄일 곳을 찾는 신호다. 규칙과 그 시험을 남기고 나머지를 줄인다. kit 이 원본보다 더 나간 곳(훅, `AGENTS.md` 의 규칙 표, kit 에만 있는 스킬)은 원본에 맞춰 되돌리지 않는다.

`[기타]` 는 대개 버린다. 원본이 모델 기본값이나 역할별 추론 강도를 바꿨으면 `/dev:setup` 과 `skills/mode/SKILL.md` 「서브에이전트」 절의 기본값에 반영할지 본다.

## 3. 대응표와 기준 커밋을 고친다

- 원본에 새 스킬이 생겼으면 `docs/authoring.md` 대응표에 줄을 더한다. 옮기면 kit 이름을, 안 옮기면 `(옮기지 않음)` 과 이유를 쓴다.
- 모든 커밋을 정했으면 `README.md` 의 「(커밋 <sha>)」 를 스크립트 끝 줄이 알려 준 원본 `main` 커밋으로 바꾼다. 일부만 처리했으면 처리한 마지막 커밋으로 바꾼다. 기준 커밋을 올리면 그 앞의 변경은 다시 보이지 않는다.
- `python3 -I .claude/skills/upstream/upstream.py` 를 다시 돌려 「원본 폴더를 건드린 커밋 0개」를 본다.

## 4. 내보낸다

`.claude-plugin/plugin.json` 판을 올리고 `python3 scripts/check.py` 를 돌린 뒤 PR 을 연다. PR 본문 `## What` 에 원본 커밋마다 한 줄씩, kit 대상마다 「반영 / 이미 있음 / 버림」과 이유를 쓴다. 다음에 따라잡는 사람은 이 PR 을 보고 왜 버렸는지 안다.

## 스크립트를 고칠 때

`python3 -I .claude/skills/upstream/upstream.py --self-test` 가 README 줄 읽기, 대응표 읽기(`a + b`, `a, b`, `create/maintain-x`, `principle-*`, `(옮기지 않음)`), 원본 경로를 kit 대상으로 바꾸기를 시험한다. `scripts/check.py` 가 이 시험을 돌린다. 원본 구조가 바뀌어 대상을 잘못 찾으면 그 경우를 시험에 먼저 더하고 고친다.
